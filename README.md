# To-Do App ✅

A simple and interactive To-Do application built with HTML, CSS, and JavaScript. It allows users to add, complete, and delete tasks while keeping their tasks saved in the browser using Local Storage.

## 🚀 Live Demo

[View Live Demo](https://todo-app-weld-xi-60.vercel.app/)

## 📌 About the Project

This To-Do App was built to practice JavaScript fundamentals and DOM manipulation.

The application allows users to manage their daily tasks through a simple and clean interface. Tasks are stored using the browser's **Local Storage**, so they remain available even after refreshing or reopening the page.

## ✨ Features

* ➕ Add new tasks
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* 💾 Automatically save tasks using Local Storage
* 🔄 Tasks remain after page refresh
* 📱 Responsive user interface
* 🎨 Simple and clean design

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Local Storage API

## ⚙️ How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/mani2643/Todo-App.git
```

2. Navigate to the project directory:

```bash
cd todo-app
```

3. Open `index.html` in your browser.

No additional dependencies or installation are required.
